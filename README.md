# ❖ WatchMe — Precision Time Tracking & Analytics

A modern, high-precision responsive stopwatch web application built for seamless time measurement, split tracking, and performance analytics. Developed using HTML5, CSS3, and modern Vanilla JavaScript.

---

## 🚀 Overview

**WatchMe** is designed to provide an intuitive time-tracking experience with an enterprise-grade dark glassmorphic aesthetic. The application features a dynamic SVG ring progress indicator, automated split metrics analysis, color-coded lap evaluation, and instant CSV data export capabilities—built entirely with native web technologies.

This project fulfills **Task 02: Stopwatch Web Application** for the **SkillCraft Technology Web Development Internship**.

---

## ✨ Features

* **Precision Time Engine:** High-accuracy timer displaying elapsed time down to hundredths of a second (milliseconds).
* **Interactive Control Suite:** Responsive action triggers for **Start**, **Pause**, **Lap**, and **Reset** operations.
* **Dynamic Ring Progress:** Circular SVG timer indicator that visually animates active lap progression in real time.
* **Split Analytics Engine:** Automated metrics engine calculating key statistics on every lap split:
  * Total split count tracking.
  * Best (fastest) lap determination.
  * Worst (slowest) lap determination.
  * Running average lap duration.
* **Performance Highlighting:** Dynamic visual color-coding in the lap history feed distinguishing fastest (green) and slowest (red) splits.
* **Data Export:** Single-click exporter converting all recorded split data into downloadable `.csv` spreadsheet logs.

---

## 🛠️ Tech Stack

* **HTML5:** Semantic markup structure.
* **CSS3:** Custom styles, CSS variables, Flexbox, Grid layouts, glassmorphism backdrop filters, and SVG keyframe/dashoffset animations.
* **JavaScript (ES6+):** State management, precise time diffing logic, DOM manipulation, metrics calculations, and dynamic CSV blob generation.
